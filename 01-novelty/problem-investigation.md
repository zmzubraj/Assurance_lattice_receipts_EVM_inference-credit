# Problem Investigation

Status: `DRAFT`; novelty is `UNRESOLVED` and this document is not independently verified.

## Problem

EVM settlement can bind bytes, signatures, and state transitions, but it does not by itself establish that an AI-inference result is semantically acceptable, produced under current authority, drawn from an authorized evidence origin, or within the scope claimed by the submitter. Existing PoI artifacts show the practical consequence: a cryptographically traceable run can still end in a negative semantic disposition. If a protocol converts any one positive signal into credit, a strong signal can compensate for a failed or inapplicable signal and create evidence laundering.

The bounded publication problem is therefore:

> How can a local EVM receipt kernel prevent credit activation whenever any required assurance dimension is failed, inconclusive, stale, mismatched, unauthorized, synthetic-without-authorization, or out of scope, while remaining deterministically replayable and locally measurable?

The problem is not to prove general LLM correctness, invent optimistic dispute, replace zero-knowledge inference, or claim production deployment.

## Causal bottleneck

The smallest decisive uncertainty is whether a typed receipt and a non-compensating decision rule can preserve evidence distinctions through the complete `evidence -> receipt -> credit` transition.

The proposed state vector is:

`A(r) = (execution, semantic, authority, provenance, freshness, origin_scope, bindings)`

Credit activation is permitted only when every required component meets its prespecified threshold and every binding is exact. Formally, for required dimensions `D`:

`eligible(r) = bindings_ok(r) AND all(A_d(r) >= theta_d for d in D)`

This is a meet-like rule: one failing required dimension cannot be repaired by a high score on another dimension. The causal claim fails if implementation paths bypass this rule, if ambiguous states are coerced to pass, or if the rule is indistinguishable from close prior art after claim-matched comparison.

## Assumptions

| Assumption | Class | Current status | Consequence if false |
| --- | --- | --- | --- |
| Required assurance dimensions can be represented as finite typed states | convenient simplification | untested | exhaustive state enumeration may be invalid or incomplete |
| Hash and identifier equality are adequate for local artifact binding | bounded engineering assumption | plausible locally | substitution resistance would be overstated |
| Authority and freshness can be evaluated from explicit signed metadata | hypothesis | untested for ALR | stale or replayed authority may pass |
| Semantic disposition is an input to settlement, not a proof generated by the EVM | scope constraint | confirmed by intake | paper cannot claim on-chain semantic correctness |
| Existing E3 negative evidence may be reused only within its historical scope | authority constraint | documented with hash drift | E3 evidence must be qualified or excluded |
| Local Foundry measurements can support only local gas/boundedness claims | evidence constraint | confirmed by intake | no mainnet or production-cost generalization |

## Falsifiers

1. A credible predecessor already implements the same typed assurance dimensions, exact binding checks, non-compensating eligibility rule, EVM credit transition, and comparable adversarial evaluation.
2. Any failed, inconclusive, stale, unauthorized, mismatched, or out-of-scope state activates credit in the exhaustive matrix.
3. Replay, downgrade, substitution, type-confusion, or authority-epoch mutation activates credit.
4. Python reference semantics and Solidity semantics disagree for any prespecified state.
5. Gas or state growth violates the frozen boundedness threshold.
6. The historical E3 chain cannot be honestly reconciled enough to support even the narrow negative-case provenance claim.
7. Independent review finds that the dimensions are labels without a materially distinct enforcement mechanism.
