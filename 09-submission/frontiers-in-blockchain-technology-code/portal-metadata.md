## Title

Assurance-Lattice Receipts for Fail-Closed Ethereum Virtual Machine Inference Credit: A Reproducible Development Study

## Keywords

blockchain assurance; Ethereum Virtual Machine; verifiable artificial-intelligence inference; fail-closed authorization; provenance; reproducible software evaluation

## Scope statement — draft, accountable-human approval required

This Technology and Code manuscript presents a deliberately narrow software prototype for fail-closed blockchain authorization of artificial-intelligence inference credit. The prototype keeps execution, semantic, authority, provenance, freshness, evidence-origin, claim-scope, and exact-binding dispositions typed and non-compensating through an Ethereum Virtual Machine gate. Its contribution is an auditable decision contract, separate Python and Solidity implementations, exhaustive enumeration of a frozen 729-state model, seven binding mutations, deterministic rejection reasons, and a provenance-preserving artifact bundle. The work fits Blockchain Technologies because it studies how blockchain software can enforce evidence and authorization boundaries for agentic inference without converting missing or failed assurance into a compensating score. The present evidence is development-level only: novelty remains unresolved, protocol review was not independent before execution, the adversarial set is bounded, no fair gas comparator exists, and external or field validation has not been completed. These limitations are explicit so that reviewers can evaluate the exact software claim rather than infer production safety, semantic correctness, or general impact. Submission additionally requires an approved public repository with DOI or URI, license, accountable authorship, declarations, and human verification.
